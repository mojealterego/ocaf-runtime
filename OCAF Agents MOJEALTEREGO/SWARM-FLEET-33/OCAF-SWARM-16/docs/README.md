# OCAF-SWARM-16

Kompletny kontrakt roju `OCAF-SWARM-16` dla specjalizacji **desktop-macos**.

- Zakres: macOS packaging, signing and entitlements
- Członkowie: 3 osobnych agentów
- Stan: `STRUCTURED_NOT_DEPLOYED` / `DRAFT`
- Handoff: claim the next eligible stage after verified completion
- Healthcheck: `health/healthcheck.sh`
- OSTc: `DISABLED`; `ACTIVE`: `DENY`
