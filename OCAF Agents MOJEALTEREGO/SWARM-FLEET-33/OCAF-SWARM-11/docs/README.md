Kompletny kontrakt roju `OCAF-SWARM-11` dla specjalizacji **builder-code**.

- Zakres: supported Code DSL parsing and diagnostics
- Członkowie: 4 osobnych agentów

- Healthcheck: `health/healthcheck.sh`
- OSTc: `DISABLED`; `ACTIVE`: `DENY`
