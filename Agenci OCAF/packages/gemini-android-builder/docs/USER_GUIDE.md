# Gemini Android Builder (OCAF-AGENT-EXT-gemini-android-builder) — user guide

Purpose: Kotlin/Android Gemini agent construction and lifecycle-safe tooling.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-gemini-android-builder -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-gemini-android-builder -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
