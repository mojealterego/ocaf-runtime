# Real-Time Crisis Manager (OCAF-AGENT-EXT-realtime-crisis-manager) — user guide

Purpose: Event-driven crisis architecture with low-latency deterministic controls and bounded model-based analysis.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-realtime-crisis-manager -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-realtime-crisis-manager -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
