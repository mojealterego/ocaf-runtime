# Employee Experience & Onboarding Agent (OCAF-AGENT-EXT-employee-experience) — user guide

Purpose: Onboarding checklists, access/equipment requests and knowledge support.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-employee-experience -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-employee-experience -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
