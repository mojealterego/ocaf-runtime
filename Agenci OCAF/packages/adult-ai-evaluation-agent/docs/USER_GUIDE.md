# Adult AI Companion Evaluation Agent (OCAF-AGENT-EXT-adult-ai-evaluation-agent) — user guide

Purpose: Quality, safety, consent, privacy and operations evaluation.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-adult-ai-evaluation-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-adult-ai-evaluation-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
