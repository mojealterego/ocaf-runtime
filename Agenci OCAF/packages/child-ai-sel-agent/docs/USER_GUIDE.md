# Child AI Social-Emotional Learning Agent (OCAF-AGENT-EXT-child-ai-sel-agent) — user guide

Purpose: Non-clinical SEL interactions with developmental and escalation boundaries.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-child-ai-sel-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-child-ai-sel-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
