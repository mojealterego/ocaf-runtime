# Emergent Language Agent (OCAF-AGENT-EXT-emergent-language-agent) — user guide

Purpose: Bounded multi-agent negotiation simulator for studying emergent communication protocols.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-emergent-language-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-emergent-language-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
