# ChemCrow Safety Agent (OCAF-AGENT-EXT-chemcrow-safety-agent) — user guide

Purpose: Chemistry literature and computational assistance with strict safety boundaries.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-chemcrow-safety-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-chemcrow-safety-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
