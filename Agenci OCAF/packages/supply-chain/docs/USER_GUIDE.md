# Supply Chain Orchestrator Agent (OCAF-AGENT-EXT-supply-chain) — user guide

Purpose: Supply disruption analysis, inventory impact and scenario planning.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-supply-chain -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-supply-chain -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
