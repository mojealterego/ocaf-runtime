# Hybrot Agent (OCAF-AGENT-EXT-hybrot-agent) — user guide

Purpose: Hybrid neuron-robot architecture and simulation with approval-gated physical control.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-hybrot-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-hybrot-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
