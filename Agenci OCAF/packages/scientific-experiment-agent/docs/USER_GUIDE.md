# Scientific Experiment Agent (OCAF-AGENT-EXT-scientific-experiment-agent) — user guide

Purpose: Scientific experiment design, hardware-in-the-loop orchestration, data integrity and reproducible analysis.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-scientific-experiment-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-scientific-experiment-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
