# Gemini Multi-Agent Orchestrator (OCAF-AGENT-EXT-gemini-multiagent-orchestrator) — user guide

Purpose: Bounded delegation, memory, approvals and observability for multi-agent Gemini systems.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-gemini-multiagent-orchestrator -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-gemini-multiagent-orchestrator -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
