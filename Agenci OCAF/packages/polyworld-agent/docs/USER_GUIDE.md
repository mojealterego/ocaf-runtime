# Polyworld Agent (OCAF-AGENT-EXT-polyworld-agent) — user guide

Purpose: Artificial-life simulation with evolving digital organisms, genomes and neural controllers.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-polyworld-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-polyworld-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
