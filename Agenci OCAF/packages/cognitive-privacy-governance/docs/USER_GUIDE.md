# Cognitive Privacy Governance Agent (OCAF-AGENT-EXT-cognitive-privacy-governance) — user guide

Purpose: Governance for sensitive behavioral and biometric data.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-cognitive-privacy-governance -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-cognitive-privacy-governance -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
