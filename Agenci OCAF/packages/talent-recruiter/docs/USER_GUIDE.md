# AI Talent Scout & Recruiter (OCAF-AGENT-EXT-talent-recruiter) — user guide

Purpose: Job-relevant candidate evidence mapping and recruiting workflow support.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-talent-recruiter -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-talent-recruiter -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
