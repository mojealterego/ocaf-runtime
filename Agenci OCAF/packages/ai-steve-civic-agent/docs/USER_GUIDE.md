# AI Steve Civic Agent (OCAF-AGENT-EXT-ai-steve-civic-agent) — user guide

Purpose: Neutral civic aggregation and deliberation simulator without voter targeting or persuasion.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-ai-steve-civic-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-ai-steve-civic-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
