# Regulator Energii (OCAF-AGENT-EXT-youth-ai-energy-regulator) — user guide

Purpose: Voluntary planning for social energy, pacing, breaks and personal boundaries.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-youth-ai-energy-regulator -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-youth-ai-energy-regulator -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
