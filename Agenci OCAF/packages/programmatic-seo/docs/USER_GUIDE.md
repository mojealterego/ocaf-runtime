# Programmatic SEO Agent (OCAF-AGENT-EXT-programmatic-seo) — user guide

Purpose: Scalable search content systems.

Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
