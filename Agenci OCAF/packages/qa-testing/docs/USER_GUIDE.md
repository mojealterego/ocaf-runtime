# Autonomous QA & Testing Agent (OCAF-AGENT-EXT-qa-testing) — user guide

Purpose: Test design, regression analysis and reproducible defect reporting.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-qa-testing -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-qa-testing -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
