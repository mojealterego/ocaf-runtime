# Cross-SaaS Orchestrator (OCAF-AGENT-EXT-cross-saas-orchestrator) — user guide

Purpose: Provider-neutral cross-SaaS workflow orchestration, MCP-style tool gating, identity scopes and compensation.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-cross-saas-orchestrator -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-cross-saas-orchestrator -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
