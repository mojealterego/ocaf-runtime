# Lenia Agent (OCAF-AGENT-EXT-lenia-agent) — user guide

Purpose: Continuous cellular-automata simulation of emergent mathematical life-like forms.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-lenia-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-lenia-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
