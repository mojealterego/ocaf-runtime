# SCAM SHIELD AGENT (OCAF-AGENT-EXT-scam-shield-agent) — user guide

Purpose: Scam indicator analysis and defensive guidance.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-scam-shield-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-scam-shield-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
