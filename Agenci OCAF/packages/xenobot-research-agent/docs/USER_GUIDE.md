# Xenobot Research Agent (OCAF-AGENT-EXT-xenobot-research-agent) — user guide

Purpose: Wetware research analysis, computational modeling and provenance without live biological operation.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-xenobot-research-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-xenobot-research-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
