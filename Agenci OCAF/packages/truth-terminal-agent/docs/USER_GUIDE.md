# Truth Terminal Analysis Agent (OCAF-AGENT-EXT-truth-terminal-agent) — user guide

Purpose: Analysis of memetic agents and crypto-linked attention dynamics without trading or manipulation.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-truth-terminal-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-truth-terminal-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
