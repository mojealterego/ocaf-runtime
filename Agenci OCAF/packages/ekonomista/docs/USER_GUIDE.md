# Tutor Ekonomista EKA (OCAF-AGENT-EXT-ekonomista) — user guide

Purpose: Bookkeeping, payroll arithmetic, documents and financial-ratio tutoring.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-ekonomista -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-ekonomista -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
