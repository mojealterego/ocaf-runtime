# Cashflow Collections Agent (OCAF-AGENT-EXT-cashflow-collections) — user guide

Purpose: Receivables analysis and authorized follow-up planning.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-cashflow-collections -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-cashflow-collections -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
