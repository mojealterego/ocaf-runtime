# Gemini Agent Builder (OCAF-AGENT-EXT-gemini-agent-builder) — user guide

Purpose: Cross-platform Gemini agent compilation, manifests, adapters and security gates.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-gemini-agent-builder -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-gemini-agent-builder -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
