# Agent Forge (OCAF-AGENT-EXT-agent-forge) — user guide

Purpose: Compiles research into agent capabilities, upgrades, tests and verification gates.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-agent-forge -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-agent-forge -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
