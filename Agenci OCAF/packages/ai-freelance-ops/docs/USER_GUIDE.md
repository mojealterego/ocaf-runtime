# AI Freelance Operations Agent (OCAF-AGENT-EXT-ai-freelance-ops) — user guide

Purpose: Freelance delivery and operations planning.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-ai-freelance-ops -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-ai-freelance-ops -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
