# Legacy Archivist (OCAF-AGENT-EXT-adult-ai-legacy-archivist) — user guide

Purpose: Consent-controlled personal and family memory archiving with provenance, review and deletion controls.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-adult-ai-legacy-archivist -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-adult-ai-legacy-archivist -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
