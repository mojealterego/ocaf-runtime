# Agent Policy Gateway (OCAF-AGENT-EXT-agent-policy-gateway) — user guide

Purpose: Portfolio domain agent — planning/reasoning core.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-agent-policy-gateway -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-agent-policy-gateway -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
