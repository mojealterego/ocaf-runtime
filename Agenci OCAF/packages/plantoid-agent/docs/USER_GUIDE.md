# Plantoid Agent (OCAF-AGENT-EXT-plantoid-agent) — user guide

Purpose: Simulation of blockchain-linked generative art organisms and virtual economic lineage.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-plantoid-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-plantoid-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
