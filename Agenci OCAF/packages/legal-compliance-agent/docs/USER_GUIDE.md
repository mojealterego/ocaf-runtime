# Legal & Compliance Agent (OCAF-AGENT-EXT-legal-compliance-agent) — user guide

Purpose: Traceable legal-information analysis, agentic RAG, citation enforcement and compliance evidence mapping.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-legal-compliance-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-legal-compliance-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
