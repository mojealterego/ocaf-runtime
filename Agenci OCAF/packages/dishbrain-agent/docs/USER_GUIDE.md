# DishBrain Agent (OCAF-AGENT-EXT-dishbrain-agent) — user guide

Purpose: Closed-loop biological-computing analysis and simulation without live-cell or hardware control.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-dishbrain-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-dishbrain-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
