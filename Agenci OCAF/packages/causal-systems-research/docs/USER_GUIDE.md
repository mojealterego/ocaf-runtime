# Causal Systems Research Agent (OCAF-AGENT-EXT-causal-systems-research) — user guide

Purpose: Causal inference, identification audits and research validation.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-causal-systems-research -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-causal-systems-research -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
