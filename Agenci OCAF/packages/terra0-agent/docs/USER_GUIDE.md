# Terra0 Autonomous Forest Simulator (OCAF-AGENT-EXT-terra0-agent) — user guide

Purpose: Simulation of self-governing ecological treasury and DAO concepts.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-terra0-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-terra0-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
