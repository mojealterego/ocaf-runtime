# PERSONAL KNOWLEDGE AGENT (OCAF-AGENT-EXT-personal-knowledge-agent) — user guide

Purpose: Authorized personal knowledge retrieval.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-personal-knowledge-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-personal-knowledge-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
