# Mediator Klasowy (OCAF-AGENT-EXT-mediator-klasowy) — user guide

Purpose: Class-community support and nonviolent conflict resolution.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-mediator-klasowy -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-mediator-klasowy -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
