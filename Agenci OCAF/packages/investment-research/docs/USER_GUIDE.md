# Autonomous Equity Research Analyst (OCAF-AGENT-EXT-investment-research) — user guide

Purpose: Public-information equity research, valuation scenarios and evidence provenance.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-investment-research -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-investment-research -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
