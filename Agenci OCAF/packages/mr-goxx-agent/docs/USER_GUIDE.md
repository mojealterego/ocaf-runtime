# Mr. Goxx Trading Simulator (OCAF-AGENT-EXT-mr-goxx-agent) — user guide

Purpose: Reproducible paper-trading simulation inspired by sensor-selected allocation.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-mr-goxx-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-mr-goxx-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
