# Autonomous DevOps / SRE Agent (OCAF-AGENT-EXT-devops-sre) — user guide

Purpose: Alert triage, incident correlation and bounded remediation proposals.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-devops-sre -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-devops-sre -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
