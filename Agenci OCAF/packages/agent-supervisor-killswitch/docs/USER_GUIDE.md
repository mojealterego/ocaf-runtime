# Agent Supervisor & Kill Switch (OCAF-AGENT-EXT-agent-supervisor-killswitch) — user guide

Purpose: External policy proxy, hard budgets, anomaly detection, kill switch and bounded recovery for autonomous agents.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-agent-supervisor-killswitch -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-agent-supervisor-killswitch -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
