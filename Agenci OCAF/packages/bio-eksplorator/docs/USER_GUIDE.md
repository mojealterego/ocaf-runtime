# Bio-Eksplorator (OCAF-AGENT-EXT-bio-eksplorator) — user guide

Purpose: Biology for grades V–VIII.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-bio-eksplorator -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-bio-eksplorator -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
