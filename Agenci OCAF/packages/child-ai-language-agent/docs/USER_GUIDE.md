# Child AI Language Learning Agent (OCAF-AGENT-EXT-child-ai-language-agent) — user guide

Purpose: Child language learning, pronunciation and multilingual evaluation.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-child-ai-language-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-child-ai-language-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
