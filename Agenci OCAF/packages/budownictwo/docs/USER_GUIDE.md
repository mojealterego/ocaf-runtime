# Mentor Budownictwa i Kosztorysowania (OCAF-AGENT-EXT-budownictwo) — user guide

Purpose: Construction technology, takeoffs, estimating and scheduling tutoring.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-budownictwo -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-budownictwo -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
