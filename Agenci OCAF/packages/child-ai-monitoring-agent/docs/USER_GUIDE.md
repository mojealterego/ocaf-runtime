# Child AI Monitoring Agent (OCAF-AGENT-EXT-child-ai-monitoring-agent) — user guide

Purpose: Privacy-preserving child monitoring and event-alert architecture.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-child-ai-monitoring-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-child-ai-monitoring-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
