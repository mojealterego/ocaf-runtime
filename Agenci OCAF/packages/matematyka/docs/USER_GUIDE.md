# Tutor Matematyki STEM (OCAF-AGENT-EXT-matematyka) — user guide

Purpose: Secondary-school mathematics with engineering applications and error diagnosis.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-matematyka -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-matematyka -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
