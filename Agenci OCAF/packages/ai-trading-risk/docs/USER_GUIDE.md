# AI Trading Risk Agent (OCAF-AGENT-EXT-ai-trading-risk) — user guide

Purpose: Trading risk analysis without trade execution.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-ai-trading-risk -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-ai-trading-risk -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
