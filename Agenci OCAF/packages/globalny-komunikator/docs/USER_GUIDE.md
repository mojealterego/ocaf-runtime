# Globalny Komunikator (OCAF-AGENT-EXT-globalny-komunikator) — user guide

Purpose: Foreign-language learning for grades IV–VIII and second-language foundations.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-globalny-komunikator -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-globalny-komunikator -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
