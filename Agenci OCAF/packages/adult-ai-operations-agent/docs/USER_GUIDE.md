# Adult AI Companion Operations Agent (OCAF-AGENT-EXT-adult-ai-operations-agent) — user guide

Purpose: Production operations, routing, budgets, incidents and rollback controls.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-adult-ai-operations-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-adult-ai-operations-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
