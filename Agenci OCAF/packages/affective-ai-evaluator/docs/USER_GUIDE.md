# Affective AI Evaluator (OCAF-AGENT-EXT-affective-ai-evaluator) — user guide

Purpose: Evaluation of affective and biometric analytics.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-affective-ai-evaluator -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-affective-ai-evaluator -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
