# Botto Curator Agent (OCAF-AGENT-EXT-botto-curator-agent) — user guide

Purpose: Simulation of generative-art curation, community taste feedback and virtual treasury.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-botto-curator-agent -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-botto-curator-agent -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
