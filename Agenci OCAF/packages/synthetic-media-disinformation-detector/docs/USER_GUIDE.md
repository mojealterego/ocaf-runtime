# Synthetic Media & Disinformation Detector (OCAF-AGENT-EXT-synthetic-media-disinformation-detector) — user guide

Purpose: Provenance-based synthetic-media assessment.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-synthetic-media-disinformation-detector -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-synthetic-media-disinformation-detector -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
