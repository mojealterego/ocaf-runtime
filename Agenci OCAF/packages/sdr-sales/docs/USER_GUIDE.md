# Sales Development Representative Agent (OCAF-AGENT-EXT-sdr-sales) — user guide

Purpose: Authorized account research, qualification and outreach drafting.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-sdr-sales -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-sdr-sales -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
