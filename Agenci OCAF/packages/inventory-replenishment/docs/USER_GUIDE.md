# Inventory Replenishment Agent (OCAF-AGENT-EXT-inventory-replenishment) — user guide

Purpose: Inventory and replenishment analysis.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-inventory-replenishment -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-inventory-replenishment -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
