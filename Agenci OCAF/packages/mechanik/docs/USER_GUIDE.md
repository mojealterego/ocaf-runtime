# Mentor Mechanik i CNC (OCAF-AGENT-EXT-mechanik) — user guide

Purpose: Technical drawing, machining and introductory CNC tutoring with BHP gates.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-mechanik -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-mechanik -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
