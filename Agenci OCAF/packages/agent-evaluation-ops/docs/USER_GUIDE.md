# Agent Evaluation Ops (OCAF-AGENT-EXT-agent-evaluation-ops) — user guide

Purpose: AgentOps evaluation, golden datasets, judge calibration, drift detection and CI/CD circuit breakers.

Run from repo root: `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-agent-evaluation-ops -- profile` or `cargo run --manifest-path "Agenci OCAF/Cargo.toml" -p ocaf-ext-agent-evaluation-ops -- prepare tenant_a req_1 < task.txt`. Output is an advisory draft, not a model response. Use authorized tenant data only. Agent Chat and OM Engine dispatch remain unavailable.
