Granica wykonania

Lokalny edytor nie uwierzytelnia tenantów. Tryb Cloud korzysta wyłącznie z jawnych żądań do uwierzytelnionego gateway; bez podłączonego serwera nie działa. Nie ma wykonania agentów, podpisywania, wdrożenia ani publikacji.

Dane lokalne pozostają w pamięci przeglądarki. Dane chmurowe są zapisywane wyłącznie na żądanie z kontrolą rewizji CAS. Eksport JSON pozostaje niepodpisany.
